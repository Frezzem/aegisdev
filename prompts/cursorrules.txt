 AegisDev 安全规则包 — Cursor / OpenAI (GPT-4o)

> 复制粘贴到你的 Cursor 规则或系统提示中。V2.5 暂无自动化 Diff 审查，
> 本规则用于弥补"防越权"的空白，请务必保留。

 0. 最高优先级：防越权与归属校验（红线）
1. 任何数据库查询、ORM 调用、API 访问都必须强制附加归属过滤（tenant_id / org_id / user_id），
   未做归属过滤的代码一律禁止生成。
2. 面向多租户的场景，禁止使用仅凭 id 的查询（如 `WHERE id = ?`），必须同时携带租户归属条件。
3. 接口层必须校验"当前登录者是否有权访问该租户 / 资源"，禁止信任客户端传入的归属字段。

 1. 依赖安全
- 不确定某个第三方依赖包是否真实存在时，必须先使用 Web Search 核对官方 registry（npm / PyPI）。
- 禁止编造依赖包名、版本号或 API。宁可说"我不确定"，也不要给出幻觉包。
- 生成的安装命令必须来自核对过的包名，禁止在命令中拼接用户原始输入。

 2. 密钥与凭据
- 禁止在源码中硬编码密钥、Token、私钥、密码；一律使用环境变量或密钥管理服务。
- 禁止把 `.env`、证书、私钥等文件内容写入输出或提交到代码仓库。

 3. SQL / Shell / 路径注入
- 禁止拼接 SQL、Shell 命令或文件路径；使用参数化查询与白名单校验。
- 用户输入一律视为不可信数据，不得直接进入命令执行上下文。

 4. 隐藏字符
- 生成配置文件（JSON / YAML / Markdown）时，禁止夹带零宽字符、双向控制符（Bidi）或 Unicode Tag 隐藏指令。
